CCMC registry of product assessments

This registry contains the most up-to-date version of our product assessments. Assessments are considered active as long as they are published here. Assessments that have been withdrawn are no longer in the registry but are available upon request by contacting the CCMC at ccmc@nrc-cnrc.gc.ca or 613-993-6189. Users should consult the registry to verify an assessment’s publication status and version (last modified date) prior to its use.

JSON Application Programming Interface (API) alternative format

This index page is available for access by digital systems through the CCMC Registry of Product Assessments JSON Application Programming Interface (API). An API is an interface that allows for communication between different software systems. The registry uses JSON (JavaScript Object Notation) to structure the information in the assessments according to the specifications in the table below. Each API record represents one CCMC product assessment. 

API specificatons
Field Value Description
Id Number The unique identifier of the assessment. 
ccmcno String The unique seven-character CCMC number assigned to the assessment that can be found on the product and in product literature (e.g., "03240-L"). 
organization_eng String The name of the assessment holder organization in English. 
organization_fre String or null The name of the assessment holder organization in French (if different from English). 
website_eng String or null The website of the assessment holder organization in English. 
website_fre String or null The website of the assessment holder organization in French (if different from English). 
organization_id Number The unique identifier of the assessment holder organization. 
status_eng  String "Active" The status of the assessment holder in English. (Currently only "Active" assessments are included in the registry; this may change in the future.) 
status_fre String "En vigeur" The status of the assessment holder in French. (Currently only "Active" assessments are included in the registry; this may change in the future.)  
ispublished String "Y" A flag indicating whether the assessment is published. (Currently only published assessments are included in the registry; this may change in the future.) 
product_eng String A list of product names (trade names) in English, separated by a vertical bar (|), that are included in the scope of the assessment. 
product_fre String A list of product names (trade names) in French, separated by a vertical bar (|), that are included in the scope of the assessment. 
refdoc_eng  Array of Objects A list of evaluation directive documents, in English, used to evaluate the product, presented in an array form for machine readability. 
refdoc_fre 
Array of Objects A list of evaluation directive documents, in French, used to evaluate the product, presented in an array form for machine readability. 
mfs 
Array of Objects 
A list of MasterFormat numbers presented in an array form that describe product categories with their intended uses through a numerical coding system.
